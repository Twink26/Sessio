§ 01 — The loop

Three steps, running quietly in the background.

01

Track

Every file edit, git commit, and terminal error during your session is captured automatically — no manual logging, no setup per-project.

02

Summarize

When you step away, an AI summary turns raw activity into a sentence you'd actually write yourself: what you touched, what broke, what shipped.

03

Recap

Next time you open the project, the sidebar shows exactly that — so the first five minutes go to coding, not remembering.

§ 02 — Opt-in, not surveillance

A public feed, only when people choose to share it.

Sharing is off by default. When a developer opts in, their session summary appears on a live public feed — real activity, no fake teammates, no demo data standing in for users.

§ 03 — Get started

Install it now

Three commands. No Marketplace listing required yet.

git clone https://github.com/Twink26/Sessio.git
cd Sessio
npm install && npm run compile

Then open the folder in VS Code and press F5 to run it in the Extension Development Host.

§ 04 — How to get started

From clone to your first recap.

01

Clone and open the project

Run the three install commands above, then open the resulting Sessio folder in VS Code (File → Open Folder).

02

Run it in development mode

Press F5 (or Run → Start Debugging) inside VS Code. This opens a second VS Code window called the Extension Development Host — this is a sandbox copy of VS Code with Session Recap already running inside it. You'll see a notification confirming "Session Recap extension is now active."

03

Open the sidebar panel

In that new window, open any project folder. Look at the Explorer panel on the left — scroll down and find a section labeled "Session Recap." Click it to expand. It will be empty the first time, since no session has been tracked yet.

04

Code like you normally would

Edit files, save them, make git commits, run things in your terminal. Session Recap tracks all of this automatically and silently in the background — there's nothing to turn on or configure for basic tracking.

05

Get your AI summary

When you close or reload the window, your session is saved. The next time you open the sidebar, you'll see an AI-generated summary of what you did, a list of edited files, your recent git commits, and a productivity score — so you instantly remember where you left off.

06

Optional: share to your private dashboard

If you want your sessions to show up on your live dashboard (the one linked elsewhere on this page), open the Command Palette (Ctrl+Shift+P) and run "Session Recap: Opt In to Team Sharing." From then on, each session you finish is also sent to your dashboard automatically.

§ 05 — Questions

Frequently asked, candidly answered.

Does anything leave my machine by default?

No. Session tracking and the AI summary run locally. Sharing to the public feed is a separate, explicit opt-in setting — off unless you turn it on.

What does the AI summary actually use?

It calls OpenAI's API when you provide a key. Without a key, it falls back to a rule-based summary generated from your real file and commit activity — never a placeholder.

Why isn't this on the VS Code Marketplace yet?

It's early. The extension works end-to-end today; Marketplace publishing is a planned next step, not a blocker to using it from source.

Can I see the code before installing?

Yes — the full source, including the sharing API and dashboard, is public on GitHub.
